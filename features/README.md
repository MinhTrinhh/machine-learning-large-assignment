# Extracted features

Save the DistilBERT embedding arrays and labels as `.npy` or `.h5` files here. Include metadata recording the pretrained model, tokenizer, pooling method, maximum sequence length, sample ordering, split, dimensions, and label mapping. Large generated arrays may be omitted from Git if the submission zip or a clear download link contains them. TF-IDF sparse matrices may be saved separately (for example, compressed sparse NPZ).
