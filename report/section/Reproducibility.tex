\section{Reproducibility and Artifacts}
\label{sec:reproducibility}

The executable notebook is \path{notebooks/task2_pipeline.ipynb}. It installs dependencies, 
downloads and verifies the data, performs EDA, extracts both feature representations, 
trains both classifiers, and exports results without a personal cloud-drive mount. 
Supporting code is separated by responsibility:

\begin{itemize}
  \item dataset retrieval and validation: \path{modules/data_downloader.py};
  \item EDA and visualization: \path{modules/text_eda.py} and \path{modules/plotter.py};
  \item shared preprocessing: \path{modules/data_preprocessor.py};
  \item TF-IDF and GloVe representations: \path{modules/feature_extractor.py};
  \item classifier definitions: \path{modules/models.py};
  \item model tuning and final fitting: \path{modules/trainer.py};
  \item validation, model selection, and held-out evaluation: \path{modules/evaluator.py}; and
  \item all visualizations: \path{modules/plotter.py}.
\end{itemize}

The fitted TF-IDF matrices are stored as compressed sparse \texttt{.npz} files. 
Dense GloVe training and test matrices and their aligned labels are stored as \texttt{.npy} 
files, satisfying the required embedding-file format. JSON metadata records representation 
identity, array dimensions, row ordering, label files, and class names. Generated EDA tables 
are stored under \path{outputs/generated/eda/}, consolidated test metrics 
under \path{outputs/generated/test_metrics.csv}, and report-ready figures 
under \path{outputs/graphics/}.

The notebook is the single execution front end. A fresh Google Colab runtime can 
use \textbf{Runtime $\rightarrow$ Run all} to reproduce downloading, feature extraction, 
experiments, and evaluation without mounting a personal cloud drive.
