\section{Introduction}

\subsection{Problem Statement}
This project addresses the five-class sentiment classification of English-language tweets 
posted during the COVID-19 pandemic, requiring models to predict one of five ordered sentiment 
labels: \textit{Extremely Negative, Negative, Neutral, Positive, or Extremely Positive}. 

The methodology encompasses exploratory data analysis (EDA), leakage-safe data preparation, 
feature engineering, model selection, and held-out evaluation using Logistic Regression and 
linear Support Vector Machines (SVMs). 

To isolate and compare the impact of text representations, the workflow evaluates both traditional 
word-level TF-IDF features and modern pretrained GloVe-Twitter-100 embeddings utilized as a fixed 
feature extractor. Both representations are evaluated under identical classifiers, data 
partitions, selection metrics, and official test sets to ensure performance differences stem 
directly from the feature representation rather than experimental variance. 

Furthermore, the modern approach is strictly constrained to a fixed embedding feature extractor 
and does not encompass an end-to-end neural network training pipeline or 
separate deep-learning pipeline extensions.

\subsection{Dataset}
The selected \textit{Coronavirus Tweets NLP -- Text Classification} dataset contains an 
official training file with 41,157 rows and an official test file with 3,798 rows. 
Each row contains anonymized identifiers, a user-provided location, posting date, tweet text, 
and a manually assigned sentiment label.

\subsection{Research Questions}
\begin{enumerate}
  \item What class balance, text-length patterns, and structural characteristics are present in the training tweets?
  \item How do Logistic Regression and linear SVM perform with TF-IDF and GloVe-Twitter-100 features?
  \item Which representation better separates adjacent sentiment intensities, and what do the errors reveal about each representation?
\end{enumerate}

\subsection{Scope}
\begin{itemize}
  \item \textbf{Exploratory Data Analysis (EDA) and Preprocessing:} Dataset inspection followed by controlled, leakage-safe text normalization.
  \item \textbf{Feature Extraction:} Sparse word-level TF-IDF vectorization alongside pretrained GloVe-Twitter-100 embedding retrieval and pooling.
  \item \textbf{Artifact Serialization:} Export of dense GloVe feature matrices and target labels as \texttt{.npy} files.
  \item \textbf{Model Selection and Validation:} Three-fold cross-validation for hyperparameter tuning, verified against a separate validation holdout set.
  \item \textbf{Final Refitting and Evaluation:} Final model training and held-out evaluation on the official test set.
\end{itemize}
