\section{Conducted Experiments}
\label{sec:experiments}

The experiments compare two feature families and two linear classifiers under the same data protocol. Parameter selection uses three-fold stratified cross-validation on the development subset, followed by confirmation on the separate validation subset. The official test set is excluded from every selection decision.

\subsection{Test Configurations}

For TF-IDF, the experiment compares word unigrams with word unigrams plus bigrams. 
Logistic Regression tests $C \in \{0.5,1.0\}$, and linear SVM tests $C \in \{0.5,1.0,2.0\}$. 
For GloVe, Logistic Regression tests $C \in \{0.5,1.0,2.0\}$, and linear SVM uses the same 
three values. All configurations use the same random seed and the same cleaned train/validation partition.

The Cartesian search therefore evaluates 8 TF-IDF Logistic Regression candidates, 12 TF-IDF linear-SVM candidates, and 6 candidates for each GloVe classifier. With three folds, these correspond to 24, 36, 18, and 18 cross-validation fits, respectively, before scikit-learn refits the best candidate on the complete development subset.

\subsection{Cross-Validation Selection}

Table~\ref{tab:selected-settings} lists the configuration selected for each feature-model pair. None of the four selected configurations used balanced class weighting. The selected TF-IDF configurations used unigrams, indicating that adding bigrams did not improve development cross-validation macro-F1 enough to be selected.

\subsection{Validation Results}

TF-IDF was clearly stronger than mean-pooled GloVe on the validation subset. TF-IDF linear SVM produced the highest validation macro-F1 (0.5842), narrowly ahead of TF-IDF Logistic Regression (0.5825). GloVe Logistic Regression was the best embedding configuration at 0.4441 macro-F1.
