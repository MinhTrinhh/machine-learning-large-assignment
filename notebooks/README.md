# Colab notebook

Create the assignment front end as a Google Colab notebook and save/export the `.ipynb` file here. It must install dependencies and download/extract the IMDb public archive in the runtime so **Runtime → Run all** works without a personal-drive mount. The notebook should perform text EDA, TF-IDF extraction, frozen DistilBERT embedding extraction, traditional classifier comparison, evaluation, and `.npy` exports. Follow the workflow and submission checklist in the repository `README.md` and report.
